Criptografía de curva elíptica: Versión aditiva de DLP, conjunto de puntos en un curva elíptica

Conjunto definido en un mundo discreto, definido por rectas.

Definimos operación de suma:
  - Adicion de puntos R = P + Q
  - Doblado de puntos R = P + P = 2P
  - Multiplicacion escalar de un punto R = nP = P + 2P
  
Para sumar puntos A y B, se traza una recta definida sobre los 2 puntos, luego, en la intersección contra la recta original, se espeja.
Al multiplicar se hace una tangente sobre el punto, la intersección de esa recta se luego se espeja

Atacable por computación cuantica, pero nos sirve para algunas aproximaciones

Cripto Agilidad
Capacidad de realizar la sustitución de algoritmos criptográficos, así como el material criptográficos, con el objetivo de mejoras a la seguridad de forma transparente
Involucra 3 capacidades:
  - Las máquinas deben poder seleccionar sus algoritmos de seguridad en tiempo real y en funcion de sus funciones de seguridad combinadas.
  - Capacidad de añadir nuevas funciones o algoritmos criptográficos al hardware o software existente.
  - Capacidad de retirar sin problemas los sistemas criptográficos que se han vuelto vulnerables u obsoletos.
  
Air Gap: Si tenemos un dispositivo que tiene un sistema desactualizado (por ejemplo un SW que solo funciona en Windows 7), este dispositivo debe meterse dentro de un "air gap", aislando el dispositivo del resto.

Por que es necesaria la cripto agilidad?
  - Las aplicaciones que usan cifrado o PKI deben inventariarse y obtener información de como y cuales algoritmos se utilizan.
  - Se deben identificar los reemplazos adecuados para los casos de uso.
  - Los nuevos algoritmos no son sustitutos directos, se deben probar alternativas.
  - El uso de productos criptográficos deben identificarse y buscar con los proovedores un programa de reemplazo.
  
Estandares: FIPS 203 - FIPS 204 - FIPS 205

La escala de tiempo para el cambio (5-7 años) supera los plazos de rotación de los tomadores de desición, por lo que es "problema de otra persona".

Los estándares del NIST son lentos en salir, lo que deja a organizaciones con versiones no-estándar de los algoritmos.

Retículos
Paralelepipedo fundamental:
Sea L un retículo construido sobre una base {v_1,...v_n}
El dominio fundamental del Retículo L es la región definida como:

  F(v1,...vn) = {t_1.v_1 + ... + t_n.v_n | t_i \in [0,1)}

Tambien conocido como det(L)

Es el area delimitada por el paralelepipedo generado por los vectores base

Matriz base: B = {v_1,...v_n}

Sea L un Retículo de rango completo de base L(v_1,...v_n) y un dominio fundamental asociado F = (v_1,...v_n)
El volumen de F es det(B) (creo)

det(B') = det(AB) = det(A)det(B) = det(B)

Elegir una base diferente no altera el Retículo

Un retículo puede particionarse en dominios fundamentales disjuntos, cuya unión cubre la totalidad del mismo

span(L) = {F + v | v \in L}

Para cualquier vector w \in R^n existe un único vector t \in F tal:

w - t \in L(B)

w = v + t
t = w - v <- el t es el punto del retículo mas cercano

w mod B = w - B . [B^{-1} . w] <- translada un paralelepípedo al origen, se dice reducir modularmente

Sea L un reticulo n dimensional con dominio fundamental F, la longitud del vector mas corto != 0 puede interpretarse como la distancia minima entre 2 vectores del reticulo

\lambda_1(L) = min(||v|| v \in L != 0)
\lambda_1(L) = min {||x - y|| x, y \in L , x != y}

SVP: Shortest vector problem
Dado una base B de un reticulo L(B) se quiere encontrar una instancia del vector diferente de cero
  v \in L(B)\{0}
tal que 
  ||v|| = \lambda_1(L(B))

SIVP (shortest independent vector problem)
CVP (closest vector problem)

Encontrar el vector mas cercano a un vector target
Dado una base B de un reticulo L(B) y un vector t \nin L(B) se requiere encontrar un vector
  v \in L(B)
tal que \forall w \in L(B) satisface
  ||v - t|| <= ||w - t||

BDD: problema de decodificación de distancia acotada
Dado una base B de un reticulo L(B) n-dimensional y un vector t \in R^n que satisface dist(t,B) <= \alpha . \lambda_1 (L)
Se requiere encontrar un vector v \in L que sea el vector más cercado tal que \forall w \in L(B)
  ||v - t|| < = ||w - t||

LWE (problema de aprendizaje con errores)
Resolución de un sistema de ecuaciones lineales las cuales se expresan como
  Ax = B
Se puede interpretar el sistema de ecuaciones como un conjunto de vectores.

La idea de LWE es recuperar el valor de una llave s a partir de un sistema de ecuaciones lineales las cuales estan contaminada de ruido e, proveniente de una distribución gaussiana

  Sea Z_q = Z/qZ
  Z^n_q = {(a_1,...,a_n), a_i \in Z_q}
  x <phi- Z^n_q
  T = R/Z <x- \= [0,1) (tomo un elemento entre 0 y casi 1 siguiendo una distribución x)
  
(<x- significa tomo un elemento del conjunto con una distribución X)

Donde n es tal que n = 2^k
Se tiene un valor fijo s \in Z^n_q y la distribución x sobre Z, por ende se conforma la distribución LWE como
  A_{s,x} sobre Z^n_q x Z_q

A <- U(Z^{mxn}_q}
s <- U(Z^n_q)
e <- D_{Zm, \alpha q} small compared to q
A, As + e -> find s

e es el ruido que se le agrega
