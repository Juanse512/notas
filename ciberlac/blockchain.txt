Blockchain: Tecnología que soporta la Web 3.0

  - Arquitectura descentralizada
  - Propiedad y control de datos
  - Menor dependencias de intermediarios
  - Participación y propiedad digital

Transacción centralizada:

  Emisor -> Plataforma central -> Receptor

Una entidad central valida y procesa la transacción

Transacción descenralizada:

  Emisor -> Red distruibuída -> Receptor

La red distribuída valida y registra la transacción

Tecnologías Web3 - Características

  - Las transacciones son validadas por diferentes nodos independientes
  - Las transacciones validadas se registran en una base de datos compartida de tipo append
  - Las funciones hash criptográficas enlazan y protegen los registros de la blockchain frente a modificaciones no detectadas

Blockchain resuelve 3 problemas:

  - Lograr que computadoras independiente se pongan de acuerdo sobre datos compartidos sin una autoridad central
  - Creación de objetos digitales únicos
  - El establecimiento y transferencia de propiedad de dichos objetos

Trilema de blockchain (limitación de blockchain):

  Escalabilidad/Seguridad/Descentralización

El reto es equilibrar estas tres características en una red, modificar una de estas afecta a las otras dos.

Que es blockchain?
Base de datos descentralizada que se mantiene mediante consenso y se distribuye entre multiples nodos, por lo que permite un almacenamiento inmutable ordenado y transparente

Red punto a punto
  - Nodos participantes
    -- con par de llaves asimétricas (wallet)
    -- Distribución de paquetes
  - Nodos validadores
    -- Protocolo de consenso

Base de Datos distríbuidas
  - Función hash
  - Árbol de Merkle

Mecanismos de seguridad

  - Funciones hash
    -- proof of work hace la inversa de una función hash
  - Arbol de Merkle
    -- Es una estructura donde cada nodo hoja está etiquetado con el hash criptográfico de un bloque de datos
    -- Los nodos que no son hojas se etiquetan con el hash de sus nodos hijos
    -- Permiten verificar eficiente y seguramente el contenido de grandes estructuras de datos

Características generales

Una plataforma pública y sin permisos normalmente permite:
  - Consultar la blockchain libremente
  - Enviar transacciones
  - Crear cuentas o direcciones
  - Operar nodos
  - Participar bajo las reglas del protocolo
  - Verificar independientemente el estado de la red

No existe una única organización que controle el registro

Smart contracts: Programas ejecutados por la blockchain, cuando la plataforma lo soporta

Capa:
  - Layer 0: infraestructura para conectar o construir blockchains
    -- Blockchain que implementa: consenso, validación de transacciones, producción de bloques, seguridad de red, costos de transacción, lenguajes de smart contracts, estado y almacenamiento, herramientas de desarrollo (Bitcoin, Ethereum, Solana, etc.)
  - Layer 1: Blockchain base donde se alcanza consenso y se registran transacciones
    -- 
  - Layer 2: Protocolos sobre Layer 1 que mejoran escalabilidad u ofrecer nuevas features
  - Aplicaciones: Wallets, exchanges y otros servicios usados por usuarios


Mainnet
  - Red blockchain real
  - Activos con valor
  - Transacciones permanente
Testnet
  - Red pública para pruebas
  - Activo sin valor económico
  - Comportamiento similar a Mainnet
Red Local
  - Blockchain ejecutada en nuestro equipo
  - Control total del entorno
  - Ideal para desarrollo y pruebas

Una cuenta blockchain se relaciona con:

  Clave privada
    - Debe permanecer secreta
    - Permite autorizar operaciones
  Clave pública
    - Se deriva criptográficamente de la clave privada
  Dirección
    - Identifica una cuenta o destino dentro de la red

La blockchain no necesita conocerla identidad real del usuario para verificar una firma

Elementos básicos de smart contract

  Estado
    - Datos persistentes, saldos, propietarios, configuración
  Funciones
    - Operaciones que pueden ejecutarse
  Reglas
    - Condiciones que deben cumplirse
  Eventos
    - Registro de acciones relevantes
  Control de acceso
    - Quien puede ejecutar ciertas operaciones

Que significa desplegar un contrato?

Compilar el contrato -> Construir transacción de desplegue -> Firmar con clave privada -> Enviar a la red -> La red valida y ejecuta la transacción -> Se crea una dirección de contrato -> Resultado: código + estado inicial + dirección.

El despliegue tiene normalmente un costo de ejecución

Interactuar con un contrato

  Lectura: Consulta información sin modificar el estado (saldo, propiertario, nombre, etc)
  Escritura: Modifica el estado y requiere una transacción (crear un activo, transferirlo, aprobar una operación, etc)

Que es un activo digital? Es una representación digital
Tiene que tener: identificador único, propietario (clave pública), cantidad, estado.

Activo nativo vs token
Nativo: 
  - Forma parte directamente del protocolo de blockchain
  - Se utiliza normalmente para pagar transacciones

Token:
  - Activo definido mediante la funcionalidad de la plataforma, frecuentemente mediante smart contract

Fungibles: Cada unidad es intercambiable por otra equivalente
No fungible: Cada activo puede ser único

Crear un activo
  - Implica registrar nueva información en el estado de la blockchain
  - Una operación de Mint puede definir
    -- Identificador
    -- Cantidad
    -- Propietario inicial
    -- Metadatos
    -- Reglas de emisión
  - No se crea un archivo, se modifica el estado mantenido por el contrato
