Red Team: 
Grupo de gente autorizada para emular un ataque de adversario. El objetivo es mostrar el impacto de ataques.

Ataque: cualquier actividad maliciosa
Malware: software malicioso
IDPS: Intrusion detetion prevention system

Ataques de Host
- Process Injection
- Rootkit
- Modify Registry
- Boot or Logon Autostart Execution
- Scheduled Task/Job
- Masquerading

Rootkit 
- User o Kernel space

Tecnicas:
- Hooking system calls
- Modificar logs del sistema


Pentesting

Guias generales:
  - PTES (PenTesting Execution Standard)
  - OSSTMM (Open Source Security Testing Methodology Manual)
  - NIST 800-115 (Technical Guide to Information Security Testing and Assessment)

Guias específicas:
- OWASP Testing guide (Web security testing guide)
- OWASP MASTG (Mobile Application Security Testing Guide)
- OWASP ASVS (Application Security Verification Standard)
- PCI DSS Penetration Testing Guidance (datos de tarjetas de pago)

Blue Team
Equipo responsable de defender un sistema de informacion manteniendo la postura de seguridad.

Threat Informed Defense: Approach que usa ataques reales para priorizar, diseñar y evaluar medidas defensivas

CSF: Cyber Security Framework

Perfiles: Describen la postura de seguridad (actual y objetivo) en función del core
Niveles: Caracterizan el rigor de las prácticas de gobernanzas y gestión
Funciones
- Gobernar
- Identificar riesgos
- Proteger
- Detectar ataques
- Responder
- Recuperar
