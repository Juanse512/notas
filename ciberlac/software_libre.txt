Creative commons -> licencia para la información
Software libre: protegido por una licencia que garantiza su libertad a la perpetuidad.
GPL - General Public Licence
4 Libertades:
  - Usar: ejecutar el programa para cualquier proposito
  - Estudiar: examinar su funcionamiento interno
  - Compartir: redistribuir copias a terceros
  - Modificar: Publicar mejoras y adaptaciones

2 Deberes:
  - Acompañar de código fuente: Entrega íntegra y transparente
  - No cambiar las condiciones: Prohibido alterar la licencia al distribuir
 
Es suficiente la libertad para garantizar la seguridad? No, existe sofware libre mal hecho, obsoleto o vulnerable.
  - Software propietario: Código fuente oculto, no se puede encontrar la vulnerabilidad a simple vista.
  - Software libre: Permite ver como fue desarrollado, inspeccionando esto se pueden ver las vulnerabilidades

La licencia protege liberatdes jurídicas, no de calidad técnicas.

Auditoria de software libre:
  - Vía técnica:
   -- Descargo el código fuente
   -- Verifico el código buscando vulnerabilidades
   -- Compilar, generando el ejecutable seguro
  - Vía sociotécnica
   -- Ver uso: si hay mucha gente que lo usa
   -- Mantenimiento: frecuencia de actualización
   -- Actividad: si las comunidades tienen foros con discusiones, y su uso
   -- Soporte: documentación suficiente y actualizada
